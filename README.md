### 03 · 开发理念

1. **行动 > 情绪。** 等情绪变好，是最大的时间黑洞。
2. **秩序外化。** 把混沌写成系统，把系统交给工具，把自己留给创造。
3. **作品是今天能力的照片。** 不修图，只重拍。
4. **工具能造的，不亲手造第二遍。**
5. **少即是多。** 黑白就够了。
